# Reference examples

This directory preserves the previous detailed English-commented demos for ABS, IK/FK, Omni, legacy APIs, per-wheel control, PS2 vector mixing and related topics.
They remain available for study and API reference but are intentionally excluded from the main Arduino IDE example menu.

Use the four project templates under `examples/` for new projects:

- `FirstMotorTest`
- `RobotTemplate`
- `PS2RobotControl`
- `VelocityControlTemplate`
