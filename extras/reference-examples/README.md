# Reference examples

Đây là archive các demo API chi tiết từ các bản trước: ABS, IK/FK, Omni, legacy, per-wheel, vector mix...
Chúng vẫn được giữ để học và tra cứu nhưng không còn xuất hiện trong menu Arduino IDE chính.

Bốn template chính nằm tại `examples/`:

- `FirstMotorTest`
- `RobotTemplate`
- `PS2RobotControl`
- `VelocityControlTemplate`
